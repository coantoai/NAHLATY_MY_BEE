# NAHLATY — cinematic 3D ready-made project verification

This pilot **tests existing public open-source 3D code**, not a manually modeled heart or engine. Its workflow clones the ORIGINAL upstream projects, runs the V8 author's own kinematics checks, tests exposed WebGL controls, records full/cutaway/exploded screenshots and public SceneCode viewer interaction, and checks Procedura prerequisites without keys or paid GPU.

- Branch: `research/cinematic-factory-test` only.
- Main/production runtime: untouched.
- No model generation API invocation, GPU rental, credential forwarding, or paid platform.
- Artifacts: `NAHLATY-3D-factory-reuse-evidence` in the isolated GitHub Actions run.
- Browser output is a **candidate assessment**, not proof of a general asset factory, scientific accuracy of cardiac anatomy, or million-scene coverage.

Working source: [V8 Engine](https://github.com/heliosv24/v8-engine), [Procedura](https://github.com/SpatiaOS/Procedura), [Multi-Agent CAD](https://github.com/Pan-Chera/Multi-Agent-CAD), [SceneCode](https://github.com/wangpuyi/SceneCode).

PASS gate: demonstrable independent WebGL geometry with original source and an interactive view change plus a successful upstream kinematics test. A separate future gate must test repeatable code generation, semantic export, commercial rights, and unit economics before declaring a factory viable.
