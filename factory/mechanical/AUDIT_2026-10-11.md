# NAHLATY Mechanical Factory v1 — Source Review

Date: 2026-10-11

## Decision

The first Universal Factory path is **mechanical / articulated systems**.

Critical path selected after source-code review:

```
mechanical meaning/spec
→ Procedura structured parametric assembly
→ deterministic geometry measurement / mate checks
→ articulation graph
→ URDF/OpenUSD validation
→ PBR lookdev
→ GLB + SceneSpec
→ existing NAHLATY Three.js runtime
```

The path is intentionally fail-closed: an artifact may be rejected, but an artifact that has not passed all hard gates cannot be marked ready.

## Upstream 1 — Procedura

Repository: SpatiaOS/Procedura  
Pinned review revision: `fac191ed49f55fcc2e0f23897e986042249f59fe`  
License: MIT

### Code facts verified

- README describes text/reference → editable procedural assembly.
- The planner decomposes into named parts rather than a monolithic anonymous mesh.
- Static mate metadata is explicitly separated from moving-joint metadata.
- `src/motion/assembly.ts` states the trust rule clearly: LLM-declared fields are soft priors; measured geometry is authoritative.
- Assembly measurement includes contact area, interpenetration evidence, contact anchors and optional coaxial alignment.
- `src/pipeline/draft-incremental.ts` compiles one part at a time, retries broken compilation, and gates disconnected parts.
- PBR material assignment exists as a dedicated stage.
- Motion export supports OpenUSD and URDF.
- URDF export is deterministic and repairs/flags unreachable or invalid articulation-tree cases.
- Optional Isaac Sim validation exists downstream.

### Status

**STRUCTURAL PASS** for the role of primary mechanical generator/orchestrator.

This is not yet an execution PASS inside NAHLATY because the complete best-quality Procedura run needs Bun, modern OpenSCAD/Manifold, Blender, an LLM endpoint and optionally Isaac Sim.

## Mechanical v1 contract

A shippable artifact must contain:
- at least two named semantic parts;
- explicit role for each part;
- geometry source for each part;
- PBR material for each visible part;
- valid joint graph;
- no unresolved parent/child or self-joint;
- loop closures represented separately from the articulation tree;
- Solid / Transparent / Cutaway / Exploded / Inside capability;
- geometry, assembly, kinematics, materials and glTF gates all PASS;
- final GLB;
- final NAHLATY SceneSpec.

Anything else is rejected before runtime.

## Remaining execution boundary

The architecture and gate logic are now coded and testable without touching production.

The only unexecuted section is the expensive/external generation chain itself: running a best-quality Procedura generation with a configured model endpoint and full native dependencies. That run is evidence after architecture approval, not a substitute for architecture.
