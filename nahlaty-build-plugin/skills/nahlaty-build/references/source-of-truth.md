# NAHLATY — SOURCE OF TRUTH

## Product
NAHLATY / MY BEE is an AI Visual Understanding Engine.

Central question:
Can any question a person wants to understand become a living interactive visual world in which camera, depth, lighting, motion, transitions, scale, zoom, cutaway, focus, transparency, 2D/3D and interaction are tools for understanding — while preserving the same world's context as follow-up questions transform it?

Core journey:
Question → Understanding → Visual World → Visual Explanation → Interaction → Follow-up → Same World Evolves.

## Governing principles
- “نحرّك المعنى لا الصورة” — animate meaning, not the image.
- The explanation is the scene, not a large explanatory UI around it.
- Minimal words; only essential labels/text.
- Motion must serve comprehension: one primary meaningful motion, subtle micro-motion when useful, intentional stillness.
- Continuity is a product property, not a cosmetic transition.
- Do not regress into dashboard cards, dense metrics, generic AI reports, or text-first chat.

## Experience
Before question: cinematic Homepage.
After question: large Main Stage + Living Ask Bar + visual journey/discovery controls.
Selecting a stage changes Main Stage smoothly without page navigation.
Follow-ups should transform/focus/edit the current visual world when appropriate.

## Visual identity
Intelligent, modern, premium, trustworthy, warm, ambitious, global.
Deep navy/black + honey-gold identity is an established direction.
Avoid neon/cyberpunk clutter and metric-card aesthetics.

## Approved experiential direction (2026-09-27)
The user should be able to look inside a subject, interact with its meaningful parts, change causal conditions, and continue discovery within the SAME recognizable visual world. This is a product direction, not evidence that the full capability has been implemented.

Hybrid visual rendering (cinematic still + composited transparent reusable motion assets / animated vector / interactive 3D; video only when justified) is an approved direction for R&D. Its specific renderer, economic advantage, and quality still require proof. See hybrid-visual-world-lab.md. Keep implementation in an isolated LAB until proven.
