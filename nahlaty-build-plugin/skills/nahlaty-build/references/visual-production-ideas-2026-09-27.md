# نحلتي — سجل تقييم أفكار الإنتاج البصري | 27 سبتمبر 2026

الحالة: قائمة أفكار للتحقيق والتجربة، وليست موافقة تلقائية على إضافة مزوّد أو شراء خدمة أو تغيير المحرك. لا تحل محل مساري العرض المنفصلين في `hybrid-visual-world-lab.md`.

## الموجود فعلًا — لا نعيد بناءه من الصفر
- مسار A: مشهد متجهي متحرك كامل؛ نموذج أولي `/vector-bee-v2`، مع حركة نحلة تلقائية وتغيير محدود لحالة اللقاح. مبني ومختبر برمجيًا، لكن لم يجتز بعد فحص الجودة البصرية عبر المتصفح.
- مسار B: صورة فوتوغرافية + أصل نحلة متحرك مستقل وشفاف؛ `/photo-overlay-v2`. التركيب وضبط الحجم/اللون/المرساتين موجود تجريبيًا، لكنه لا يحقق مطابقة إضاءة/منظور تلقائية أو واقعية سينمائية مثبتة.
- مصدر الصورة في تجربة B هو Pexels؛ الأصل المتحرك للنحلة مرسوم ومؤلف محليًا. لا ادعاء بوجود مصنع توليد أصول أو فيديو شفاف حقيقي.
- هناك أيضًا في المشروع أساس لتخطيط المشاهد/الحركة والسياق. تصنيف «موجود» لا يساوي «جاهز للإطلاق».

## NOW — تحسين المشهد والفهم، دون تبديل محرك افتراضي
1. تطوير متجهات تفاعلية مع حالات سببية قابلة للملاحظة (Rive / dotLottie مرشحان، وليس كلاهما إلزاميًا). قارن مع SVG/CSS الحالي قبل إضافة اعتماد جديد.
2. أصول حركة صغيرة قابلة لإعادة الاستخدام، مع اتصال دلالي بالموضوع بدل حركة زخرفية؛ اختبر الأداء والوضوح على الهاتف.
3. تفسير تجريبي قابل للاستمرار داخل العالم نفسه: تغيير شرط، ظهور أثر، ثم إعادة الضبط، مع ثبات هوية العناصر.
4. إنشاء قياسات فعلية: زمن أول مشهد، زمن تغيير الحالة، زمن التوليد المدفوع عند وجوده، حجم التحميل، سلاسة الحركة، وعدد طلبات API؛ لا تقديرات تسويقية.

## LAB — تجارب منفصلة قابلة للقياس
1. Depth map / Parallax: تحريك كاميرا محدود فوق صورة ثابتة، ومقارنته مع قصّ طبقات 2.5D. خريطة العمق النسبية من صورة واحدة ليست هندسة ثلاثية الأبعاد مكتملة. افحص ظهور فجوات/تشوهات عند كشف المناطق المخفية. مشروع MiDaS الأصلي مؤرشف؛ لا نعتمده كحل تلقائي افتراضي.
2. Procedural SVG / Canvas: بناء تسلسل تدفق علمي واضح خطوة بخطوة. لا نحول العرض إلى شبكة صناديق أو لوحة معلومات.
3. Transparent compositing: قيّم SVG/Lottie/WebP وفيديو شفاف مع اختبار صريح على Safari؛ MDN يذكر عدم دعم شفافية VP8/VP9 في Safari. تدرج لون CSS لا يحل الظل والاحتجاب والمنظور تلقائيًا.
4. Physics-based interactions: Matter.js ثنائي الأبعاد مرشح فقط لشرح علاقات فيزيائية ملائمة؛ Three.js للمشاهد الثلاثية الأبعاد عند الضرورة. محاكاة تعليمية يجب ألا توحي بفيزياء زائفة.
5. Micro-generation / modular assets: إعادة توليد العنصر المتغير فقط بدل إعادة إنشاء العالم. قِس حقيقةً حفظ السياق وتكلفة التوليد. ظهور تحديث محلي سريع لا يعني أن استدعاء توليد جديد ينتهي خلال 500 مللي ثانية.
6. مقارنة Qwen الحالي بصورة من FLUX/fal عند الحاجة، في LAB وبموافقة إنفاق مستقلة؛ لا نستبدل المزود. سعر FLUX.1 dev على fal مُعلن 0.025 دولار لكل ميغابكسل مع التقريب للأعلى، وليس «جزءًا من السنت لكل صورة».

## معيار الاختيار
لكل فكرة: ما الآلية التي أصبح المستخدم يفهمها أفضل؟ ما الجودة الواقعية على هاتف؟ هل السؤال التالي يغيّر العالم نفسه؟ كم استغرقت العملية فعلًا، وما تكلفة التوليد والتسليم والتخزين؟ ما المصدر والترخيص؟ لا نَعِد بمظهر «هوليوودي»، أو توفير 90%، أو صفر تكلفة، أو استجابة أقل من 500 مللي ثانية دون مقارنة مُعاد إنتاجها.
